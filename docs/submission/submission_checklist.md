### Имена файлов

- 01_jury_guide.pdf — руководство для жюри.
- 02_api_reference.pdf — API и зависимости.
- 03_submission_checklist.pdf — этот перечень.
- manifest.json — хеши актуальных PDF, схемы API и материалов, без закрытого содержимого.

Все перечисленные файлы находятся в docs/submission/. README.md в корне объясняет запуск и даёт прямые ссылки. Markdown-исходники доступны рядом с PDF для проверки текста; они не заменяют требуемый формат сдачи.

## 02 / Репозиторий и передача

| Действие перед сдачей | Фактический статус |
|---|---|
| Указать адрес репозитория | Указан: https://github.com/Lexxar91/aggratech- |
| Дать экспертам доступ на просмотр | Нужно проверить вне аккаунта команды; в этой задаче не проверено |
| Проверить получение исходников и PDF по ссылке | Нужно проверить скачивание/clone на стороне эксперта |
| Прикрепить ссылку внутри выбранной задачи | Выполняет команда; в этой задаче не выполнено |
| Передать обязательную документацию в PDF | Три готовых файла включены в комплект |

Проверяйте доступ в приватном окне или с другой учётной записи. Ссылка на закрытый репозиторий без разрешения эксперту не считается доступной сдачей. Точный вариант точечного доступа или headless Git в Q&A не был окончательно согласован: не считайте его автоматически принятым.

В исходниках для эксперта должны быть файлы сборки, lock-файлы, миграции и необходимые ресурсы. Не добавляйте .env, реальные пароли, ключи, токены, пользовательские выгрузки или реестры людей. Закрытые материалы банка передаются уполномоченным экспертам отдельно от публичной документации.

## 03 / Что проверять в работающем приложении

| Проверка | Ожидаемый результат |
|---|---|
| Обычный запуск Docker Compose | Приложение и Mailpit открываются; кабинеты наполнены |
| Новый кандидат и подтверждение email | Письмо приходит; профиль сохраняется после обновления |
| Python/SQL и черновики | Условия читаются; введённое решение сохраняется и отправляется явно |
| Уровень и публикация | Успех даёт Junior/Middle; отказ объясняет невыполненные требования |
| Потребность и подбор | Навыки и условия влияют на порядок; объяснения соответствуют расчёту |
| Предложение и согласие | Зарплата обязательна; контакты открыты только выбранной компании |
| Отзыв и несколько источников | Закрывается нужное разрешение; другие действующие сохраняются |
| Вакансия и отклик | Снимок условий неизменяем; повтор не создаёт дубликат |
| PDF | Кириллица читается; новый файл учитывает текущую приватность |
| Автономный CLI | B0/B1/B2 и четыре артефакта без БД, почты и runner |

Это ориентиры для эксперта, а не утверждение о новом ручном прогоне в ходе подготовки документов. Выполненные ранее технические проверки и результаты перечислены в руководстве и журнале.

## 04 / Как трактовать результаты честно

Банк и методика v3 проверены людьми и приняты пользователем. Технический допуск связан с актуальными хешами и полным исполнимым прогоном. Этот факт не отменяет принятие и не создаёт неподтверждённые подписи отдельных экспертов.

Численные показатели точности уровня, сопоставимости вариантов и качества подбора для реального найма не предоставлены в текущих отчётах. Для них указано «не измерено». Синтетические labels и прохождения стартовых аккаунтов не являются исследованиями людей.

ФСП сейчас подключён через тестовый адаптер; реальная интеграция описана как предполагаемая. Docker-limited — ограниченная контейнерная изоляция, не VM/gVisor и не доказательство production-безопасности.

Презентация и сценарий выступления существуют в docs/release/, но Q&A §7 не называет их заменой обязательной документации. Видео в этой задаче не записывалось и не включено в обязательный перечень §7. Не выдавайте историческую презентацию за актуальное описание, не сверив её с этим комплектом.

Публикация репозитория, настройка внешнего доступа и отправка ссылки не выполнялись: задача ограничена подготовкой документов и README.
