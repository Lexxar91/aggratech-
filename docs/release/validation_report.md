## Matching и происхождение данных

120 искусственных backend-профилей, 12 потребностей и 6 работодателей;
разделение 40/80 кандидатов и 4/8 потребностей. Паспорт и ограничения:
`fixtures/validation/stage7/passport.json`, протокол разметки —
`fixtures/validation/README.md`. Импортированные грейды служат только тестовому
DTO, не записям подтверждений в продукте.

Фиксированные веса: Score = clamp(55T + 25K + 7F + 8A + 5U − P, 0, 100).
Без ФСП F=0, остальные веса не меняются. Равные баллы: Score → T → K → candidate_id.
Базовые B0/B1/B2 сравниваются на одних данных и одном as_of, без подбора весов
по контрольной части. ФСП mock, актуальность и доступность проверяются раздельно.
Полный контроль содержит восемь потребностей; все восемь результатов сохраняются,
а среднее не подменяет их. Метрики по synthetic labels — проверка тестовых данных,
**не качество подбора для реальных работодателей**.

Человеческая разметка ещё не получена. Precision@10, Recall@20 и nDCG@10
относительно людей — **не измерено**. Неполная потребность также «не измерено»;
неразмеченная пара не считается отрицательной. Labels применяются только после
построения выдачи; замена labels не меняет порядок, баллы и объяснения.

## Сводка реальных прохождений

**Нет данных.** Подтверждённых человеческих прохождений и заполненного реестра
нет. READ ONLY-проекция сохранённых попыток и пустой реестр используются для
проверки этого состояния, без включения demo, seed, fixtures и технических прогонов.
Пустая статистика людей не означает нулевую сложность или ноль ошибок кандидатов.
Закрытые ответы и персональные идентификаторы в сдачу не включаются.

## Открытые пункты полной приёмки

1. Независимое review всех 24 версий и трёх трассировок, исходные результаты
   и approved/changes_requested по актуальным хешам; при изменениях — новый прогон.
2. Фактический зачётный допуск, реальные сохранённые прохождения, приёмка
   основного matching/сравнения/приглашений на подтверждённых профилях.
3. Предварительный эталон двух разметчиков, assessment X/Y на одном грейде
   с соблюдением семисуточного cooldown; анализ уровня, сложности, сопоставимости.
4. Два слепых разметчика matching до просмотра результатов, полный контрольный пул.
5. Добровольцы для понятности, независимый запуск, реальная репетиция и видео.

Production-нагрузка и внешний сервис ФСП не проверялись. Docker-limited не
эквивалент VM/gVisor; ядро общее, контроллер с Docker socket является доверенным
компонентом. Уже раскрытые контакты и скачанный PDF нельзя отозвать удалённо.
