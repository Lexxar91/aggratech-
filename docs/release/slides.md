# Aggratech: проверяемый прототип

- Backend Junior/Middle, assessment A/B, объяснимый matching и контактное согласие.
- Release candidate этапа 9; полная приёмка ещё не завершена.
- Текущая интеграция v3; demo и fixtures не подтверждают квалификацию.

---
# Путь кандидата и работодателя

- Две роли, Mailpit, профиль, приватность и PDF с кириллицей.
- Опрос, выбор Junior/Middle и формы X/Y; A/B: 30/15 минут, начало B за 24 часа.
- Три редактируемых шаблона потребности, снимки выдачи и объяснения.
- Приглашения: шесть статусов, предложение с зарплатой, семь суток.
- Вакансия, отклик, выбранные контакты; отзыв одного источника сохраняет другие.

---
# Банк и граница подтверждения

- V3: 28 карточек, 14 Junior/14 Middle; формы X/Y: 5 A + 2 B.
- Python 3.14 и настоящий PostgreSQL 18, включая конкурентные Y3-транзакции.
- Пакеты A/B/C/D дают 0–4; незавершённость и инфраструктурный сбой не дают нуля.
- Допуск: актуальный технический отчёт и принятие исходника пользователем.
- Статистическая точность и сопоставимость на людях этим прогоном не измерены.

---
# Общий matching и автономный CLI

- Score = clamp(55T + 25K + 7F + 8A + 5U − P, 0, 100).
- F=0 без ФСП; остальные веса сохраняются, неизвестные условия отдельно.
- Равные баллы: Score → T → K → candidate_id.
- B0/B1/B2 на одном as_of, labels только после ранжирования.
- rankings.json, metrics.json, report.md, run_manifest.json; без БД/почты/runner.

# Данные и пределы метрик

- Синтетика: 120 кандидатов, 12 потребностей, 6 работодателей.
- Разделение: 40/80 кандидатов и 4/8 потребностей; контроль — восемь потребностей.
- Synthetic labels проверяют расчёт, не качество реального найма.
- Нет разметки людей: Precision@10, Recall@20, nDCG@10 — не измерено.
- Технические UI-прохождения не считать участниками человеческого пилота.

---
# Изоляция и приватность

- Docker Compose без отдельной runner VM; worker вызывает runner по mTLS.
- Задача: сеть отключена, read-only, временная область, CPU/RAM/PID/time/output limits.
- Non-root, drop ALL, no-new-privileges, seccomp; нет банка/секретов/host mounts.
- API не имеет Docker socket. Новые карточки, контакты и PDF проверяют согласие.
- Docker-limited — ограниченное демо, не VM/gVisor и не production-безопасность.
