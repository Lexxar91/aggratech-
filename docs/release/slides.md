# Изоляция и приватность

- Docker Compose без отдельной runner VM; worker вызывает runner по mTLS.
- Задача: сеть отключена, read-only, временная область, CPU/RAM/PID/time/output limits.
- Non-root, drop ALL, no-new-privileges, seccomp; нет банка/секретов/host mounts.
- API не имеет Docker socket. Новые карточки, контакты и PDF проверяют согласие.
- Docker-limited — ограниченное демо, не VM/gVisor и не production-безопасность.
