# Банк этапа 1

`blueprints.json` — матрица запланированных X/Y, а не допуск полного банка.
`private/stage1.json` — служебные материалы X1/X4 для junior/middle:
условия, перенос, рубрики, эталоны, альтернативы, ошибки и проверочные данные.
Не раздавать каталог через API, static-files или PDF кандидата.

Технический прогон выполняется командой `python -m app.tools.bank_quality`:
Python исполняется только через настроенный mTLS runner. При недоступности
runner отчёт имеет статус `incomplete`, ни одна Python-версия не допускается.
Один успешный технический отчёт не заменяет взаимную проверку материалов
двумя участниками команды и не доказывает сопоставимость сложности на людях.

Для X4 подготовлены два правильных решения и три класса ошибок на грейд.
Кандидат задаёт 2–3 JSON-случая; произвольный тестовый код не принимается.
Обязательные классы: остановка после первой страницы и дубли записей.
Дополнительный: запрос после признака завершения. Результат входит в рубрику
связанного навыка; отдельного бонуса и дополнительных доказательств нет.
